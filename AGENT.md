# AGENT.md

## Проект

**ProfitBox** — одностраничное веб-приложение для учёта товаров, продаж и прибыли.  
Весь код находится в одном файле: `profit_tracker_v6_2.html`.  
Никаких фреймворков, никаких зависимостей, никаких сборщиков — только ванильный JS, HTML и CSS.

---

## Структура файла

```
profit_tracker_v6_2.html
├── <style>         — весь CSS включая темы и @media мобильную адаптацию
├── <body>          — статичная HTML-разметка (модалки, навигация, контейнеры)
└── <script>        — весь JS: стейт, рендер, логика, хранилище
```

Данные хранятся в `localStorage` под ключом `ptv5`.  
Резервные копии — в `localStorage` под ключом `ptv5_backups`.

## Правила для агента

### Делай только то, что явно указано в задаче

- Не рефакторь код, который не затронут задачей
- Не переименовывай переменные и функции без причины
- Не меняй структуру файла (не разбивай на несколько файлов)
- Не добавляй npm, библиотеки, import/export, TypeScript

### Формат изменений

- Все правки — в одном файле `profit_tracker_v6_2.html`
- CSS добавляй в существующий блок `<style>`, не создавай новый
- JS добавляй в существующий блок `<script>`, не создавай новый
- Сохраняй минифицированный стиль существующего кода (без лишних переносов и пробелов в JS)

### Стейт и данные

- Глобальные переменные состояния объявлены в секции `// STATE` — не дублируй их
- Все изменения данных должны вызывать `persist()` в конце
- Не меняй схему данных в localStorage без миграции (см. `loadData()`)

### Рендер

- Все вкладки рендерятся через `render()` → `renderProducts / renderAnalytics / renderHistory / renderStock`
- Не используй прямую манипуляцию DOM за пределами функций рендера, кроме `liveUpdate()`
- После изменения данных вызывай `persist(); render();`

### Мобильная адаптация

- Брейкпоинт мобилки: `max-width: 768px`
- Нижняя навигация — `#mobile-nav`, управляется через `switchTab()`
- Боковая панель на мобилке — drawer через `toggleMobileSidebar()`
- Поля ввода должны иметь `font-size: 16px` на мобилке (иначе iOS делает zoom)

### Чего не трогать

- Систему тем (`setTheme`, CSS-переменные `:root`, `.theme-*`)
- Логику резервных копий (`createBackup`, `restoreBackup`, `tryAutoBackup`)
- Кастомный календарь (`CAL`-объект)
- Функции экспорта (`doExport`, `doExportExcel`)
- Логику склада (`updateStock`, `updateMinStock`)

## Ключевые функции — справочник

| Функция | Назначение |
|---|---|
| `render()` | Полный перерендер текущей вкладки |
| `persist()` | Сохранить в localStorage + flash + liveUpdate |
| `switchTab(tab)` | Переключить вкладку |
| `productById(id)` | Найти товар по id |
| `calcFor(list)` | Посчитать rev/cost/exp/profit для списка товаров |
| `filteredProducts()` | Текущий список с учётом папки и поиска |
| `addSale()` | Записать продажу из формы истории |
| `quickSell(id)` | Быстрая продажа из каталога |
| `setDiscountType(type)` | Переключить тип скидки `'currency'`/`'percent'` |
| `createBackup(type)` | Создать копию `'auto'`/`'manual'` |

## Проверка после изменений

1. Скобки в JS сбалансированы (открытых `{` = закрытых `}`)
2. Функции `persist()` и `render()` вызываются там где надо
3. На мобилке (≤768px) раскладка не ломается
4. localStorage-ключ `ptv5` не изменился (совместимость с существующими данными)
