# scfbas2

📦 ProfitBox — учёт прибыли и склада

**Текущая версия: v2.4**

ProfitBox — это веб-приложение для учёта товаров, продаж, прибыли и склада.
Работает прямо в браузере, без установки и сервера.

🚀 Возможности
📋 Каталог товаров
добавление, редактирование, удаление
учёт себестоимости, цены и расходов
группировка по папкам
📊 Аналитика
выручка, прибыль, расходы
топ товаров
динамика продаж
🕓 История
учёт продаж
учёт закупок
фильтры по датам и товарам
🏪 Склад
остатки товаров
минимальный запас
индикаторы (норма / мало / нет)
🎨 Темы интерфейса
тёмная, светлая, океан, фиолет и др.
💾 Работа с данными
сохранение в JSON
загрузка данных
экспорт в Excel и CSV
резервные копии (авто + ручные)


## Демо-версия
- Файл: `ProfitBox_v2.0_demo.html`
- Доступны только вкладки: **Каталог** и **История**
- Экспорт (JSON / CSV / Excel) отключён
- Темы: только **тёмная** и **сепия**

## Changelog

### v2.4
- Переработана архитектура операций: добавлены отдельные сущности `saleDocs` и `supplyDocs` (документы + строки), а таблицы истории строятся из них.
- Поставки теперь поддерживают несколько товарных позиций в одном документе.
- В аналитике добавлена отдельная графа расходов, синхронизированная с источником расходов из истории.
- Загрузка изображений в карточке товара переведена на файловый режим (PNG/JPG/JPEG) с превью и валидацией.
- Обновлена миграция/совместимость: старые `sales`/`purchases` автоматически переводятся в новую структуру без потери данных.
